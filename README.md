# குறள் 571 · கண்ணோட்டம் (The Look of Grace)

An interactive website explaining Thirukkural 571, built for a creative hackathon with **HTML, CSS and vanilla JavaScript only**.

> கண்ணோட்டம் என்னும் கழிபெருங் காரிகை
> உண்மையான் உண்டிவ் வுலகு

## Idea
கண்ணோட்டம் literally means "the look of the eye". The Kural is hidden in the dark and only appears where the visitor's light (their gaze) falls, so the act of looking carries the meaning.

## Features
- Lantern-light reveal of the Kural
- Seven animated word scenes
- Drag-to-compare "with and without grace" city
- Mini quiz and floating lanterns

## Run
Open `index.html` in a browser. No build step.
